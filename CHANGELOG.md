# Changelog

## 0.2.0 — Full first level

- Replaced the single wave arena with six connected areas across a 92 × 186 unit footprint.
- Placed 53 enemies, including selected patrols, guarded wards, mixed encounters, and the Bellkeeper.
- Added proximity awareness, pursuit, navigation around obstacles, and return-to-home behavior.
- Added two ward objectives, a locked gate, supply caches, a shrine checkpoint, and a playable level ending.
- Removed timed spawning, wave counters, and swarm announcements.
- Added a navigation map, contextual interactions, and checkpoint recovery.
- Preserved both third-person cameras and all seven weapons.
- Expanded automated coverage to 26 tests and documented the exact encounter layout.

## 0.1.0 — Initial playable prototype

- Added an original gothic horde arena with third-person isometric and shoulder cameras.
- Added zombies, demons, and heavy monsters, plus four melee and three ranged weapons.
- Added touch and keyboard controls, defense, healing, pickups, escalating hordes, and restart.
- Kept combat simulation separate from presentation for quick balance changes.
- Added automated combat regression checks and a manual browser/device test guide.
