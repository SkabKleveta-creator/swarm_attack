# Changelog

## 0.1.0 — Initial playable prototype

- Added an original gothic horde arena with third-person isometric and shoulder cameras.
- Added zombies, demons, and heavy monsters, plus four melee and three ranged weapons.
- Added touch and keyboard controls, defense, healing, pickups, escalating hordes, and restart.
- Kept combat simulation separate from presentation for quick balance changes.
- Added automated combat regression checks and a manual browser/device test guide.
